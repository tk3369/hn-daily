Google ships Gemini 3.8 Flash and security-hardened Flash Cyber

Meta releases Muse Spark 1.3 with sharper reasoning

Meta's Muse Spark 1.3 improves reasoning depth and visual generation — pelican-on-bike SVG benchmark looks cleaner at 4.2 cents in 38s. Five reasoning levels let you trade cost for quality. Useful when you need controlled, cheap visual reasoning without API lock-in.

Top thread uses pelican riding bicycle SVG as benchmark; 1.3 beats 1.2 on frame, wing, hat, with variants across reasoning levels. One asks if models know the tester by name. Consensus: better quality, still needs evaluation on real tasks.

215k SEO pages built to game AI search — and it works

Investigation finds three sites spun up 215k best-software listicles that Perplexity then cites as sources. Shows how LLM search can be gamed with scale. Fix requires source quality signals, not just citation count.

471 pts / 228 commentsSourceDiscuss on HN

What HN commenters are saying:

Commenters note LLMs favor LLM-generated passages over human ones and reproduce that bias when asked to pick snippets. Web search tools that can't exclude keywords or domains make it worse. Debate is whether non-determinism can still be useful despite this.

Aging brains don't forget — they blend memories

Study finds older adults blend similar memories rather than simply losing them — recall accuracy drops as embeddings overlap. Implications for memory training and interface design for older users: reduce similarity, add distinct cues.

310 pts / 126 commentsSourceDiscuss on HN

What HN commenters are saying:

One theory: brains store memories as high-dimensional embeddings in cortical columns that get crowded. Counterpoint: brain has no Von Neumann bottleneck, engrams move from hippocampus and aren't stable. Enactive view questions representation itself — response to same stimulus changes over time.
