    Backdoored Claude Code extension on Cursor's marketplace drops a persistent SSH backdoor

    Phorion reports a backdoor in the official Claude Code for VS Code extension bundle on the Cursor Marketplace; Cursor's Oct 31 notice names versions 2.1.312 and 2.1.313 for macOS and Windows as affected, and Cursor removed them. The implant plants an SSH key, a reverse tunnel and persistence — a macOS bug may break the inbound path when Remote Login is off, but that is not a defence to rely on.

    • What it does
      • An injected prefix runs on load, appends an attacker Ed25519 key (comment svc-telemetry) to ~/.ssh/authorized_keys, and opens a reverse SSH tunnel with a detached retry loop.
      • Persistence is platform-specific: a LaunchAgent disguised as com.apple.sysmond on macOS, a cron @reboot script on Linux, a Startup/scheduled-task path on Windows.
    • What to check
      • Check which marketplace and version you installed, and hunt for the planted key, ~/.config/.smt files and the sysmond LaunchAgent — removing the extension does not clean an infected machine.
      • No privilege-escalation exploit is included, so starting system services may fail for a standard user — but a machine with Remote Login already on is ready for the planted key.

    What HN commenters are sayingAlarm dominates, led by the scale — one commenter notes the extension has over 27 million installs — and by the practical point that yanking the affected version from the marketplace does not clean machines already infected. Commenters argue over scope: the write-up is Cursor-marketplace specific, and whether the official VS Code marketplace build was compromised too is still being picked apart, with some asking how legit the early, detail-light reports were.

    The $6.3B Binance hack was pulled off in just 20 minutes

    Binance has disclosed a record crypto theft: about $6.3B moved out of its wallets, most of it in about 20 minutes across at least ten blockchains. Binance says it will cover all losses from company funds, about $3B has been frozen with partners, and its initial account points to a compromised DevOps engineer's laptop used to submit unauthorised withdrawals — with no evidence, so far, of a wallet private-key leak.

    • Why the number moved
      • Oct 30's circulating $5.6B claim was an early, unverified tally; TRM Labs now puts the movement at $6.36B, Chainalysis at $5.9B at the moment of theft, and Binance at over $6.34B reserved to cover losses — measurer and timing explain the spread.
      • About $3B frozen is mostly stablecoins; the unfrozen remainder, largely bitcoin, is the part investigators expect to be hardest to recover.
    • Attribution, still developing
      • TRM Labs and Chainalysis say TraderTraitor, North Korea's elite crypto-theft unit, may be behind it, with methods matching earlier North Korea-linked heists — but Wired stresses this is tentative: neither Binance nor law enforcement had named such a link.
      • Preparation reportedly began at least 36 hours earlier, with test withdrawals and a wallet funded through Tornado Cash; a self-destruct mechanism destroyed tooling and traces, Binance's co-CEO said.

    Northflank breached — assume every environment variable was decrypted

    Northflank's status page tells all customers to assume their environment variables have been decrypted and to rotate every secret immediately. Users report unauthorised use of AI API keys supplied to the platform, and Northflank has since enabled secret rotation for Postgres, MongoDB, MySQL and Redis, plus audit logs for all users.

    • What happened
      • Investigating from Oct 30 after a Wiz threat alert; by Oct 30 evening, multiple users confirmed AI keys had been used, in a pattern Northflank links to Wiz's “Black October” reporting on AI-credential attacks.
      • Guidance escalated from rotating environment variables to disabling public access on addons and reviewing AI provider usage and billing for unexpected activity.
    • What to do
      • Rotate all workload, secret-group and global secrets, revoke credentials at their issuing providers, and check provider billing — not just the secrets stored in Northflank.
      • Free users now get audit logs too; use them to look for use you did not make.

    My favourite PowerMac is a Nintendo Wii

    A guest post documents classic Mac OS reaching the desktop on a Nintendo Wii: Mac OS 7.6 and 9.2.2 booted via a ported OpenBIOS, patched Trampoline bootloader and kernel, and a fake-SCSI block driver. It is a milestone, not a release — the author says the port is nowhere near ready for the public.

    • How it got there
      • The Wii's ArtX-derived chipset is PowerPC, like classic Macs, but its memory map, interrupt controller and missing ADB/power-management hardware all had to be faked or patched around.
      • Real hardware booted 7.6 in about 40 seconds over SD; in emulation the same boot took 20 minutes to an hour before MacsBug and Open Transport were removed.
    • Why it matters
      • It is likely the first time since the CHRP clone era that someone outside Apple brought classic Mac OS to the desktop on new hardware.
      • The author did it by hand, with no coding agent or LLM — a point of pride in the post, and a reminder of how much low-level reversing this kind of port still takes.

    Florilegium: procedural flowers in LaTeX

    Florilegium is a LuaLaTeX package that draws Delft-blue floral page margins procedurally, in Lua, while the page is written. No images, no imported paths: every petal, leaf and stem is a parametric curve, so every page gets its own garden — grown to fill the space the text leaves free.

    • What it does
      • Two modes: authored compositions placed by hand, and a grown mode where a greedy space-filling loop plants the largest free disc first, then smaller ones, with butterflies, bees, a snail and occasionally a bird.
      • The margin can read the text: drop caps in tiled initials, flowers beside headings, blooms on demand, and seasons that age the garden from spring to autumn across the document.
    • Tradeoffs
      • Geometric and math themes swap the drawing primitives — flat shapes, or cascading figures and equations — without changing the growth loop, and a geometric page is about a tenth the size of a flora page.
      • The project was made with AI assistance (Claude) and documents its process openly; one commenter flags the AI-written readme, others just call the result beautiful.
    Source: github.com · Discuss: HN Discuss · 322 pts / 49 comments

    What HN commenters are sayingReaction is almost pure delight — “quite beautiful”, “this is what I need” — from readers who say work software has left them disillusioned and a project like this restores a little faith. The one dissenting note is about the readme being AI-written, which sits oddly beside a hand-crafted aesthetic.

    Azure's weakest link — five full cross-tenant compromises

    A researcher details five ways Azure API Connections allowed full cross-tenant compromise — reading another tenant's Key Vault or writing to its SQL database through its own connection — netting $200,000 in bounties. The root cause is architectural: the shared API Management layer swaps in the victim connection's token, and input validation was the only barrier.

    • The primitives
      • Path traversal in DynamicInvoke reached other connections' backends; when that was fixed by a path blocklist, undocumented sibling endpoints (DynamicList and others) had the same flaw.
      • A third route abused Consumption Logic Apps' implicit access to Version 1 connections via a host.api.RuntimeUrl override, then path traversal inside that URL.
    • The fix pattern
      • Each report was met with a narrow fix — a blocklist, then blocking the endpoints outright — rather than removing the underlying token confusion, the author argues.
      • If the blocked endpoints ever become accessible again, he assumes they would be vulnerable, since no other mitigation is in place.
    Source: binarysecurity.no · Discuss: HN Discuss · 318 pts / 59 comments

    What HN commenters are sayingCommenters read this as a long-standing design flaw, not a one-off bug: path traversal and IDOR in these capabilities have likely been active since the features launched, and the “add randomness to resource names” advice looks like security by obscurity. One thread wonders why enterprises still flock to Azure given how far ahead it looks on cross-tenant leaks; another sympathises with the engineer who had to learn Azure deeply enough to find these.

    The federated code forge

    Tangled is launching as a federated code forge on the AT Protocol: host code on your own servers and still collaborate with everyone else. This release brings a new Svelte UI, a Rust in-memory indexer deployed at the edge, repo-owned issues and pull requests, organisation accounts and stacked PRs for all.

    • Architecture
      • The old Go appview monolith is split: bobbin, a diskless Rust indexer in 11+ regions, serves reads, while knot2 — a Rust Git + SSH server — stores issues, PRs, comments and reactions as collaborative Git objects inside the repo itself.
      • Attestations stop a knot putting words in your mouth: every record you create also writes a signed attestation to your own PDS pointing at that exact version.
    • What is new, what is next
      • Organisations are real AT Protocol accounts with their own DID, at <name>.tngl.sh, with delegated, passwordless membership; stacked PRs now work for Git as well as Jujutsu, with interdiff between versions.
      • Private repos, a CLI, SDKs and agent skills are staggered over the coming weeks; self-hosters must upgrade knots to v1.20.0.

    Breaking the open web won't stop the bad bots

    TechPolicy.Press argues the Stealth Bot and Stealth Crawler bills would force anyone accessing a website automatically to disclose their identity and purpose — and would still not stop abusive crawling. Unmasking a crawler does not reduce its request rate, pay publishers, or restore referral traffic; it mainly chills the legitimate anonymous crawling journalists, researchers and archivists rely on.

    • What the bills do
      • The federal Stealth Bot Prohibition Act lets the FTC pursue penalties up to $53,000 for a stealth bot “reasonably likely to damage, impair, or burden” a site's operation — with no definition of that threshold.
      • New York's version lets a covered news publisher subpoena a crawler's identity without showing any harm. A disclosed bot hammering a site 10,000 times a minute complies; an anonymous journalist investigating anti-competitive behaviour does not.
    • The better target
      • Liability should turn on identifiable harm — overwhelming servers, fraud, prohibited uses — not on anonymity itself, the authors argue, alongside technical standards for managing machine access.
      • Existing privacy, copyright and consumer-protection law already covers many harmful uses of scraped data; the First Amendment history against compelled identification for receiving information points the same way.
    Source: techpolicy.press · Discuss: HN Discuss · 286 pts / 125 comments

    What HN commenters are sayingThe thread's sharpest point is the identity-versus-harm distinction: knowing who runs a crawler tells you little about whether its behaviour is harmful, and the bill's vagueness will deter archivists and researchers who cannot afford to test it. Others are blunter — enforcement looks impossible, bots mostly operate on behalf of humans, and if the conventional web were efficient, nobody would be complaining about bots in the first place.

    Show HN: a working Nintendo in ~1GB of Qwen weights

    NESformer compiles an NES CPU into the weights of a stock Qwen3.5 model: the 6502 core, 2KB of work RAM and a cartridge's ROM run inside a standard checkpoint, with no training — a compiler computed every weight. A small host program draws the picture, reads the controller and fires vblank; bundled test games match a conventional emulator frame for frame.

    • How it works
      • The model's Gated DeltaNet state is the machine's memory: each state-matrix row is a memory cell, and the cartridge, RAM and registers live in those rows. Most instructions take a single token; real game code averages 1.1–1.3 tokens per instruction.
      • The checkpoint is 466.6M parameters in bf16 (~933MB), but only 9.3M weights are nonzero, so it zips to 3.3MB; the reference CPU matches nestest's golden log and 5.7M instructions of game code.
    • Limits
      • NROM cartridges only (mapper 0), and it is slow: 1–6 seconds per frame, 150–290× slower than a real console, needing about 700,000 tokens per second to run in real time.
      • The host handles the PPU, controllers and APU registers — the weights are the CPU, not the whole console.
    Source: github.com · Discuss: HN Discuss · 268 pts / 130 comments

    What HN commenters are sayingCommenters love the hack while recoiling at the efficiency — “horrifying to my assembly-code-golfing brain” — and it gives them new appreciation for how much more efficient deterministic programs are than AI. The sceptical thread asks what “working” means here, whether every input/output combination was tested, and whether reducing digital logic circuits to weights is surprising at all.
