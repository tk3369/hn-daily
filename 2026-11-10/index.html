Source HN Discuss 559 pts · 321 comments

5

Amazon saves millions swapping Sonnet for a decision model

Two Amazon engineers replaced Sonnet 4.6 with Strands Decider — a small decision model, not a general LLM — for labelling internal tickets, at 98% lower cost with equal performance. Projected saving: millions a year in token costs.

Source HN Discuss 478 pts · 174 comments
What HN commenters are saying

Skepticism that this is an ad dressed as a case study — Strands is AWS's own agent SDK, and the savings accrue to Amazon itself. The math joke lands anyway: 98% cheaper on millions means the 2% still isn't trivial, and the real lesson is make-vs-buy — a small purpose-built model beats a frontier LLM for a narrow classification job.

AlphaProof Code formally verifies Signal's protocol

DeepMind's new agentic framework used AI agents to mathematically prove key security properties of the actual code behind Signal's cryptographic protocol — a 'grand challenge' in software security, announced November 10.

Source HN Discuss 264 pts · 100 comments
What HN commenters are saying

Impressed that a codebase as large as Signal's checks out in a strict formal sense — 'engineers of the highest caliber.' Horrible public key tricks

Source HN Discuss 208 pts · 72 comments
What HN commenters are saying
