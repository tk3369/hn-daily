One click, universal XSS in uBlock Origin — fixed, but the trick is instructive

A researcher found a one-click universal XSS in uBlock Origin's Firefox element picker: a malicious site could embed the picker's privileged iframe invisibly, trick the user into clicking 'Create', and plant a trusted filter that runs JS on any site. Fixed now; uBO Lite had a milder variant.

Source HN Discuss 495 pts · 142 comments
What HN commenters are saying

uBO's broad permissions make any bug worse — and the same hook leaks your install-unique extension UUID to any site, a tracking identifier. Readers praise the disclosure that GPT-5.6 Sol found the bug while the author wrote the prose and Claude wrote the PoC.

Self-hosting map tiles is now cheap and easy — one file, one bucket

PMTiles packs a whole map into a single file served over HTTP Range requests — no tile server needed. Download a daily world build, drop it in a storage bucket behind a CDN that caches Range requests, and embed it. The contrast: Mapbox charges $5 per 1k loads past the free tier.

Source HN Discuss 408 pts · 72 comments
What HN commenters are saying

Questions about which clients work with the approach, and one reader's Malwarebytes flagged the demo's Bunny proxy domain. Others report running the same setup behind Cloudflare R2 for privacy and access control.
