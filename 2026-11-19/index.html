Unauthenticated RCE in Nginx — two critical HTTP/2 flaws, patch now

Wiz disclosed CVE-2026-123633 and CVE-2026-123007, two unauthenticated remote code execution flaws in Nginx's HTTP/2 handling, both rated CVSS 9.2. A remote attacker can compromise the server running Nginx — and the websites, APIs and data behind it — without logging in. Patches were released the same day; only HTTP/2-enabled servers are exposed.

Source HN Discuss 1461 pts · 613 comments
What HN commenters are saying

How long before this is exploited in the wild? is the dominant question — the write-up is unusually detailed. Some note it always seems to be HTTP/2 with Nginx. Others asked why full details dropped before patches were ready; the patches landed within 30 minutes. Five research groups independently found the same bugs, which one commenter calls a record for bug collision.

7

Ruby patches multiple Regexp and String case-conversion flaws

Ruby disclosed multiple vulnerabilities in Regexp and in String case conversion, all C-level memory-corruption bugs. The sharpest is the German ß: upcasing it expands to 'SS', growing the string by one character, and the Windows-1252 conversion code didn't handle the extra length. Patches are out for supported Ruby versions.

Source HN Discuss 304 pts · 113 comments
What HN commenters are saying

The ß bug fascinates the thread — a one-character length change in a buffer that assumed conversion never grows a string. Several note the bugs were found by autonomous AI models, including one credited to Anthropic: 'imagine attackers using [such] models at scale.' Others ask whether regexes could just be replaced with plain conditionals.

LLM-assisted reverse engineering — a field guide that actually works

A practical walkthrough of using LLMs for reverse engineering: disassembly, hypothesis-driven experiments, and steering the model to write periodic reports, then wiping context to stop it going in circles. The author's verdict is that the scientific method — definitive experiments instead of endless guessing — is what makes agents useful on hard targets.

Source HN Discuss 276 pts · 70 comments
What HN commenters are saying

Practitioners swap tooling notes: IDA Pro steers better than Ghidra, and forcing the model into experiments breaks the 'guessing loops' that plague Claude on harder targets. One warning recurs — reverse engineering has legal limits, and Apple's developer agreement bans it in some cases. Model guardrails are another friction: several use DeepSeek when Claude or OpenAI refuse.

9

Ruby2ßhell: pre-auth RCE on stock Rails from one character

Ruby2ßhell is a pre-authentication remote code execution bug in stock Rails, and it's the same ß→SS case-conversion flaw from the Ruby advisory — upcasing 'ß' expands to 'SS' and overflows a buffer that assumed length never grows. The name was crowd-chosen on HN. It lands alongside six other Ruby vulnerabilities disclosed the same day.

Source HN Discuss 262 pts · 103 comments
What HN commenters are saying

Mostly relief mixed with amusement: it's not a second, separate Rails disaster — it's the advisory's headline bug with a good name. 'For once a bug name that's cool,' one commenter says; another offers 'Scheiße2Shell.' The underlying lesson is the same as the advisory's: case conversion that changes string length was added without testing the assumption it broke.
